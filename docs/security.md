# 安全与数据处理

## 默认行为

- **无遥测**：没有埋点、没有崩溃上报、没有使用统计。
- **不上传证据**：CLI 只写本地文件；Action 只把产物上传到当前 GitHub 工作流的 Artifact。
- **不收集源代码**：收集器只请求 PR 元数据、commit 列表/SHA、review、check/status 的 REST 端点，不请求文件内容。
- **无大模型**：核心链路没有 LLM 调用，不把事实交给模型推测。
- **不持久化客户数据到仓库**：测试 Fixture 全部为合成数据；真实证据包输出目录 `dist/` 已在 `.gitignore` 中。
- **日志脱敏**：CLI 不打印 token、请求头或响应体；Action 使用 GitHub 原生 secret masking。

## 凭据

- 只从环境变量读取 token（默认变量名 `GITHUB_TOKEN`）；命令行参数传的是变量名，不是 token 值。
- 离线 `--snapshot` 模式完全不创建网络请求，也不需要 token。
- Token 不写入证据包、验证报告、Markdown 或日志。
- 推荐只读 token；明确禁止 `repo`（全量写）、`admin:*`、`workflow` 等不需要的权限。

## 网络边界

- 运行时只访问 GitHub REST API（默认 `https://api.github.com`，可通过 `GITHUB_API_URL` 指向 GitHub Enterprise 的 API）；HTTPS 强制校验，不接受 URL 中嵌入凭据。
- 分页链接只允许跟随同一 origin；不会跟随外部 URL。
- 安装依赖时会访问 PyPI；这是构建步骤，不传输客户代码或证据。
- 除 GitHub API 与包安装源外，不联系任何第三方服务。

## 产物边界

- 证据包只保存标识、时间、结论与原始记录 URL，不保存源代码正文或工单正文。
- 人工声明字段（部署、回滚、工单、例外）由使用者负责准确性；工具标为 `declared`，不做独立验证。
- 内容摘要用于检测内容变化；**不是**加密签名、防篡改证明或可信时间戳。
- 本工具不是合规认证产品，不保证通过任何审计。

## 操作建议

1. 先在测试仓库运行；不要在首次试点中给写权限。
2. 用独立的只读机器人账号或 GitHub Actions 内置 token。
3. 检查 Artifact 访问权限；包含内部部署链接的证据包应按内部资料处理。
4. 发现安全问题请通过仓库私有渠道报告，不在公开 Issue 中粘贴真实证据或 token。
