# 付费试点 Runbook（第 15—45 天）

**前提**：第 14 天问题门已通过（≥8 个团队展示过近期真实流程，≥5 个团队愿意具体讨论试点范围、权限与采购）。未通过时不要开始这份 runbook。

## 固定报价与范围

- 报价：**1,500 美元 / 6 周**，或当地等价价格；以**实际到账**为付款验证。
- 最多 **3 个仓库**；初始配置 + 一次基线复盘；支持若干次真实发布；每周一次 30 分钟反馈；最终交付使用前后对比与缺口报告。
- 不包含：无限定制、审计背书、生产环境代运维、SSO/RBAC/计费开发、通用工单平台、AI 评分。
- 免费 Community 版继续可用；免费 PoC、意向书、口头称赞**不计入**验证。

范围模板见 `docs/pilot-scope-template.md`，效果记录见 `docs/weekly-metrics.md`。

## 六周节奏

| 周 | 动作 | 交付物 | 退出条件 |
|---|---|---|---|
| 0 | 确认范围、付款到账、安全联系人、只读 token 方式 | 已签署范围与收货信息 | 未收款不进入实施 |
| 1 | 配置 1 个仓库，跑通离线样例与 Action；记录安装问题 | 首份证据包 + 基线复盘 | 15 分钟内生成第一份证据包 |
| 2 | 用 1 次真实发布验证，记录人工整理步骤与缺口 | 前后对比初稿 | 能指出具体节省步骤 |
| 3 | 覆盖第 2/3 个仓库；收集缺失字段频率 | 配置差异清单 | 区分通用需求与单客户定制 |
| 4 | 按出现频率自动化重复项（仅在付费需求重复时） | 小改动 + 验证记录 | 不引入控制面功能 |
| 5 | 让客户在真实发布中自行复用；记录支持时间 | 复用事件记录 | 非一次性样例 |
| 6 | 最终复盘：工时、周期、可见例外、续费意愿 | 效果报告 + 续费报价 | 明确转付费 / 停止 |

## 每次试点会话检查清单

1. 是否使用只读 token？权限是否与 `docs/permissions.md` 一致？
2. 是否只在 GitHub API 与包安装源之间通信？
3. 人工声明字段是否由客户自己填写并确认（部署、回滚、例外、工单）？
4. 是否明确说明“内容摘要不防篡改”“不是审计结论”？
5. 是否记录本次发布仍需的人工整理时间？
6. 是否记录客户主动复用事件？
7. 是否记录支持分钟数与阻塞原因？

## 收款门（第 45 天）

- 3 个已收款试点：进入第 46—90 天；否则停止托管控制面计划并复盘问题/客群/报价/采购。
- 有付款但需求完全不同：承认更接近咨询业务，不包装成 SaaS。
- 有使用但无人付款：按免费工具维护，不强行收费。
- 每个客户都要求的不同定制：拒绝无限定制，保持交付成本边界。

## 90 天继续投入条件

至少 2 个客户转为持续付费；在多个真实发布中重复使用；人工交付时间下降；客户能指出具体价值（减少整理工时、缩短补材料周期、暴露原本不可见的流程例外）。达不到则停止扩建。

## 禁止事项

不伪造访谈、引语、订单、收入或截图；不把未收款的意向写成付款；不使用“保证通过审计”“不可篡改”“自动合规”等表述；不把客户代码或真实证据提交到公开仓库。
