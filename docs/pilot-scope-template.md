# 付费试点范围模板（填写后发客户确认）

```text
试点名称：
客户法律实体 / 联系人 / 决策人：
报价：1500 美元 / 6 周（或当地等价：______）
付款状态：未收款 / 已收款（日期、金额，仅内部记录）
试点仓库（最多 3 个）：
  1.
  2.
  3.

包含：
  - 初始配置与一次基线复盘（60 分钟）
  - 支持若干次真实发布，生成 JSON 与 Markdown 证据包
  - 每周一次 30 分钟反馈
  - 最终使用前后对比与缺口报告
  - 只读 GitHub token，report-only，不阻断发布

不包含：
  - 无限定制、审计背书、合规认证
  - 生产环境代运维、接入私有部署系统
  - SSO / 复杂 RBAC / 计费 / 多租户控制面
  - 通用工单平台、AI 风险评分、大量第三方集成

客户责任：
  - 指定只读 token 与权限范围
  - 自行填写并确认人工声明字段（目的、工单、部署、回滚、例外）
  - 提供脱敏材料，不提交客户源代码到公开仓库

安全边界：
  - 无遥测、不收集源代码、不将客户数据用于训练
  - 证据包与产物按客户内部资料处理
  - 内容摘要仅检测内容变化，不是防篡改证明或时间戳
  - 本工具不保证通过 SOC 2 / ISO 27001 / 任何审计

成功标准（双方事先确认）：
  - 15 分钟内生成第一份证据包
  - 至少 1 次真实发布中客户主动复用
  - 记录前后人工整理时间差
  - 具体缺口列表与后续决策

签字 / 日期：
```

注意：本模板只是商业文档草案；发送客户、收款与签约需单独确认。
