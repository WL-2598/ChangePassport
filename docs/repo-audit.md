## 2. 决策

按计划中的决策规则：**空白仓库 → 默认技术栈启动**。

- 运行时：Python 3.12 为目标版本（CI 主矩阵）；当前沙箱只有 Python 3.11.2，因此代码保持 3.11+ 可运行，`requires-python = ">=3.11"`，并在 CI 同时跑 3.11 与 3.12。本地实测环境会在验收记录中如实标注。
- 形态：本地 CLI + GitHub Action + 开放 JSON Schema；JSON / Markdown 双输出。
- 边界：无后端、无数据库、无默认遥测、核心链路不调用大模型、不持久化客户源代码。
- 商业门槛：付款验证（第 45 天门）之前不开发托管控制面、SSO、RBAC、计费或多租户功能。
- 事实边界：证据包只记录 GitHub 可核实事件与人工声明；内容摘要只用于检测内容变化，不宣称不可篡改或可信时间戳；不宣称保证通过任何审计。
