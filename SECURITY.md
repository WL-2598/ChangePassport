# Security Policy

ChangePassport is a local, report-only evidence generator. It has no telemetry, no backend, and no model calls.

Full details: [docs/security.md](docs/security.md) and [docs/permissions.md](docs/permissions.md).

Please do **not** report security issues in public Issues if the report would include real customer data, tokens, or evidence packets. Use a private GitHub security advisory for this repository instead. Do not attach client code or production data.

Scope note: third-party penetration testing and customer security questionnaire responses have **not** been completed. The content digest detects content changes only; it is not a signature, tamper-proof record, or trusted timestamp.
